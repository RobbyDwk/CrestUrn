# CrestUrn

Watches user data in cloud-based spreadsheets and alerts them to changes made by others.

CrestUrn is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Watches user data in cloud-based
- spreadsheets and alerts them to
- changes made by others

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CrestUrn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
